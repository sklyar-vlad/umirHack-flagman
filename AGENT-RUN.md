# Фоновый frontend-агент

Агент работает локально в ветке `agent/frontend-autonomous`, в отдельном worktree.
Источник задач — Flow(Frontend) в YouGile, истории F01–F31. За одну итерацию
реализуется одна история; уже завершённые подзадачи сохраняются.

Используются Ralph `80ca69e`, Beads 1.3.1, Serena `949a27e`, установленный Codex CLI
и npm. Модель берётся из настроек пользователя Codex. Скрипты совместимости
адаптируют инструкцию для macOS, F-задач и npm.

## Запуск и управление

Из корня этого worktree:

```sh
./scripts/agent-control.sh start
./scripts/agent-control.sh status
./scripts/agent-control.sh logs
./scripts/agent-control.sh stop
```

Проверка одной итерации: `./run-agent.sh --once --no-sandbox`.
Повторный одновременный запуск запрещён lock-каталогом. Не удаляйте lock, пока
не проверите отсутствие процесса. `stop` посылает TERM только сохранённому
процессу этого worktree; Ralph завершает собственных дочерних исполнителей.

Один запуск ограничен 20 итерациями, 4 часами и 150 000 оценочных токенов Ralph.
Оценка Ralph учитывает размер промптов, а не точное потребление аккаунта.
Процесс завершится раньше при исчерпании очереди, блокере или ошибках. Блокер
не считается завершённой задачей. Mac должен оставаться включённым с интернетом;
caffeinate удерживает от автоматического простоя, запуск после перезагрузки
не настроен.

## Проверки и Git

`./scripts/frontend-checks.sh` запускает lint, TypeScript, Vitest и сборку.
Проверки и один conventional commit с номером истории обязательны перед Done.
Изменения остаются в агентской ветке; push и merge не выполняются. Не запускайте
второго разработчика в этом worktree одновременно с агентом.

`--no-sandbox` отключает Docker-обёртку Ralph. Codex запускается с
`--approve-for-me` (режим workspace-write уже включается этим флагом), сохраняя системный sandbox и автоматическую
проверку запрашиваемых разрешений.

## Локальные данные

Логи, PID, отчёты и Beads/Serena хранятся в игнорируемых `.ralph/`, `.beads/`,
`.serena/`. Токен и идентификаторы YouGile расположены вне репозитория, в
`~/.local/share/ralph-codex/secrets/`, с правами 0600. В проектном MCP-конфиге
указано только имя переменной `YOUGILE_TOKEN`. Не публикуйте этот каталог.
