# Поведение интерфейса

Боковое меню показывает один активный раздел, включая вложенные адреса и
совместимые ссылки. Мобильная шапка держит кнопку меню в отдельной колонке;
длинные имена не вытесняют её. Закрытие меню возвращает фокус к кнопке.

Переход страницы не переводит фокус принудительно в main. Диалоги удерживают
фокус и возвращают его инициатору; обновление данных не открывает диалог заново.
Поиск выровнен по нижнему краю поля, а не его подписи.

Большой skeleton появляется только пока нет данных для текущих параметров.
Фоновый запрос сохраняет список и форму. Запрет доступа по-прежнему скрывает
защищённые данные. Начальное чтение, ручное обновление и смена фильтров работают.

SSE реагирует на предметные изменения, resync и восстановление соединения.
Фокус окна и видимость при здоровом соединении не запускают повторное чтение.
Периодические отметки времени перечитывают данные только при пересечении срока
или порога предупреждения известной партии. При недоступном SSE сохраняется
ограниченный fallback, а не бесконечное перечитывание.

Дата показывается до минут. Секундного отсчёта до срока нет; API и точные
исходные timestamps сохранены. Поле datetime-local открывает общий русский
календарь с месяцами, днями недели и отдельным временем. Применение обновляет
форму, отмена сохраняет исходное значение, включая дробные секунды. Enter в
выборе времени применяет календарь, не отправляя родительскую форму.

Проверки: frontend lint/typecheck/Vitest/build; Playwright ui-stability,
navigation и live-updates на 360/390/1024/1440. Проверка настоящего backend
выполняется отдельным test:production без MSW.
